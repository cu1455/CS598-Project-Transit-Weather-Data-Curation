# CS 598 Project: Transit & Weather Data Curation

## Overview
This project implements an end-to-end data curation workflow to generate a high-quality, integrated dataset of public transit activity and weather conditions for the Waterloo Region. The goal is to enable analysis of how weather events affect transit service and ridership patterns.

## Project Structure
- `data/`: Contains raw, processed, and final datasets.
- `docs/`: Documentation including Data Dictionary and Quality Report.
- `scripts/`: Python scripts for each stage of the curation lifecycle.

## Prerequisites
- Python 3.x
- `pandas` library (`pip install pandas`)
- `requests` library (`pip install requests`)

## Workflow Instructions

Run the scripts in the following order to reproduce the dataset:

1.  **Acquire Data**: Download raw GTFS and Weather data.
    ```bash
    python scripts/acquire_data.py
    ```

2.  **Assess Quality**: Check data validity and generate a report.
    ```bash
    python scripts/assess_quality.py
    ```
    *Output*: `docs/quality_report.md`

3.  **Clean Data**: Handle missing values and standardize formats.
    ```bash
    python scripts/clean_data.py
    ```
    *Output*: `data/processed/weather_clean.csv`

4.  **Integrate Data**: Aggregate transit data and merge with weather.
    ```bash
    python scripts/integrate_data.py
    ```
    *Output*: `data/final/integrated_dataset.csv`
